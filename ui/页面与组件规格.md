# 页面与组件规格 —— 知境「庭院纸感」

> 本文是 6 个页面的实现规格，供 UI 实现队友按图施工。
> 视觉令牌见 `ui/tokens/`，选型理由见 `ui/选型报告.md`，交互清单见 §5。

---

## 1. 页面清单与导航结构

底部 Tab 四个主入口，详情页与对照页从内容卡片/列表项推入（返回栈）：

```
Tab（首页 | 问答 | 庭院 | 我的）
  ├─ 首页 → 内容详情 / 观点对照 / 设置
  ├─ 问答（无子页）
  ├─ 庭院 → 内容详情（下钻）
  └─ 我的 → 设置
```

| 页 | 路由 | 承载内容（对齐 6.1.2） |
|---|---|---|
| 01 首页 | Tab 1 | 问候、解析队列、最近收藏、新的关联、回顾提醒 |
| 02 问答 | Tab 2 | 对话流、引用来源、输入条；「回答中 / 本地无内容」两态 |
| 03 认知庭院 | Tab 3 | 主题树（可缩放拖动）、养成系动物、四态图例 |
| 04 内容详情 | 推入 | 正文、引用片段、备注、相关内容、观点对照入口 |
| 05 观点对照 | 推入 | 两方立场、分歧点、我的想法 |
| 06 设置 | Tab 4 | 模型档位、推理后端、回顾、权限、数据 |

## 2. 通用组件规范

| 组件 | 规格 |
|---|---|
| **内容卡** | 左侧「叶脉书签」3dp 竖条，颜色即探测状态；标题 `titleMedium`；摘要 `bodyMedium`；元信息 `bodySmall`；角标胶囊 22dp 高 |
| **四态角标** | 未探测(灰绿 8A9791) / 已验证(蓝 2E6B9B) / 已掌握(绿 3C8F5F) / 易混淆(赭黄 C0741E)；用「墨点 + 文字」表示，不靠色块堆信息 |
| **按钮** | 主按钮 = 植物绿底白字；次按钮 = 描边；文字按钮 = 无底色，危险操作用 Clay 红 |
| **输入条** | 通栏贴底，圆角胶囊；聚焦描边植物绿 + 3dp 光环 |
| **分段控件 Seg** | 胶囊容器内高亮当前项 |
| **开关 Switch** | Material 3 默认，主色 on |
| **图例** | 墨点 + 文字，横向排布 |

## 3. 认知庭院（核心页）画法

主题树是 M6-01 的视觉核心，规则：

- **节点 = 主题**，半径 = 该主题内容条数，颜色 = 探测状态（四态色）；
- **连线**：主题间关联用虚线（弱连接），点开可看关联依据；
- **冠层**：主题节点先画冠层（淡绿椭圆簇），枝干压在冠层之上，标签用背景描边「挖空」保证可读；
- **状态聚合**：某主题下命题的探测状态聚合出主题节点的颜色（回写走派生，广度侧不存状态）；
- **养成系动物**：四阶段（萌芽→幼苗→小兽→成熟），阶段由「收藏/回顾」行为驱动，展示「距离下一阶段还差 N 条」；
- **缩放**：双指缩放 + 拖动，`tree-tip` 常驻提示「双指可缩放」。

## 4. 深浅色

- 浅色「纸白」：底 `#F6F5F0`，卡 `#FFFEFA`，主色 `#2E6B4F`；
- 深色「林地夜」：底 `#121712`，卡 `#1A201A`，主色提亮为 `#7CC39A`；
- 冠层与枝干在深色下必须提亮（低透明度的绿压在近黑底上会消失），已在 `mock.css` 用 `[data-theme="dark"] .canopy { opacity: .8 }` 处理。

## 5. 交互清单（对应 6.1.3，逐条核对）

| # | 要求 | 实现 |
|---|---|---|
| 1 | 按钮 100ms 内有反馈 | 按压 90ms（`ZjMotion.pressMs`） |
| 2 | 「正在思考…」可取消 | 问答页 thinking 条带「取消」按钮 |
| 3 | 轻提示约 2.5s | 预留 `ZjMotion` 常量，实现时用 Snackbar 2500ms |
| 4 | 删数据/开权限用确认框 | 设置页「一键清空」为危险行，弹确认框 |
| 5 | 解析失败/权限未开/CPU 模式/离线明确说明 | 首页队列态 + 设置页「CPU（无可用 NPU）」「通知未开启」文案 |
| 6 | 正文 ≥14 号、支持系统字体缩放 | 正文 15sp，全 sp 单位，原型 100%/115%/130% 三档验证 |
