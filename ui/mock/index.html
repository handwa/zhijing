ReLU 后面能直接接 Softmax 吗？

不能。形状上接得上，但语义上不对。

Softmax 期望的输入是未归一化的 logits（可正可负），它内部做的是 exp(z)/Σexp(z)。而 ReLU 把负半轴全部压成 0，先丢了一半信息；再送进 Softmax，等于让一个「只剩正数」的分布去归一化，梯度分布被扭曲。

还有一个边界：当类别数 C=1 时，Softmax 恒输出 1，完全没有区分度。

为什么 ReLU 后面直接接 Softmax 会出问题

抖音 · 昨天 21:40 收藏 · 312 字

神经网络 激活函数 立场：技术解释

很多人第一次搭分类头时，都会把 ReLU 直接接在 Softmax 前面。代码不报错，loss 也在降，于是就被当成「能跑」。

但形状对得上不等于语义对。Softmax 期望的输入是未归一化的 logits，可正可负；而 ReLU 的输出全为非负数。把负半轴压成 0 之后，信息已经丢了一半，再去做归一化，等于让一个残损的分布去表达概率。

更隐蔽的是梯度：多一次 Softmax，反向时就会多乘一个 p(1-p) 因子，训练明显变慢，甚至学不动。
