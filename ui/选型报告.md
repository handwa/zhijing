# UI 方案选定报告 —— 知境

> 对应《软件需求规格说明书 V2.1》§6.1（界面）与 §7.4（开发要求）。
> 结论先行：选定 **「庭院纸感」方案**（自然有机 + 克制），并以 Material 3 作为实现基线。

---

## 1. 结论

| 决策点 | 选定 |
|---|---|
| 视觉方向 | 庭院纸感：浅色暖白纸底 + 植物绿主色 + 衬线标题 |
| 实现基线 | Jetpack Compose + Material 3（`colorScheme` / `Typography` / `Shapes` 三大主题对象） |
| 深浅色 | 跟随系统，浅色为默认；深色命名「林地夜」 |
| 动态取色 | **默认关闭**（见 §4 风险） |
| 字体 | 衬线做展示（系统 Noto Serif CJK），黑体做正文；不内嵌第三方字体 |
| 状态色 | 四态专用色，不复用 Material 语义色 |

一句话：**说明书 6.1.1 的三条硬约束（简洁、浅色为主、插画统一）正好构成一个完整的设计方向，不需要再比选风格**——真正需要决策的是「用不用动态取色」「衬线还是黑体」「状态色怎么定」这三点，本报告把它们定死。

---

## 2. 为什么是「庭院纸感」，而不是别的

候选风格有三，按与说明书的契合度取舍：

| 候选 | 优点 | 硬伤（对照 6.1.1） | 结论 |
|---|---|---|---|
| **庭院纸感（自然有机）** | 与「认知庭院」的核心隐喻一致；暖白纸底 + 植物绿，天然「简洁、浅色、轻松」 | 无 | ✅ 选定 |
| 极简黑白灰（Material 极简） | 最稳、成本最低 | 「氛围轻松一点」「庭院里的树用轻量插画」会被压成冷冰冰的工具感，与产品气质冲突 | ❌ |
| 玻璃拟态 / 渐变色 | 视觉冲击强 | 需要大量装饰层，违背「简洁」；深浅色适配成本高，插画风格难统一 | ❌ |

判定依据：说明书把「庭院」当作第一性隐喻（M6-01 认知庭院是核心页面），界面风格应当服务于这个隐喻，而不是另起一套。选型不是选「最好看的」，是选「最不偏离需求的那一个」。

---

## 3. 设计令牌（唯一色源 / 字源 / 尺寸源）

已落地为 4 个 Compose 文件（`ui/tokens/`），可直接替换 `app/.../ui/theme/` 同名文件：

| 文件 | 内容 | 关键纪律 |
|---|---|---|
| `Color.kt` | 纸墨中性色 + 植物绿主色 + 赭石强调 + 四态色 + 深色「林地夜」 | 不用纯黑纯白；主色只做关键动作；强调色全页最多一处 |
| `Type.kt` | 展示衬线 / 正文黑体，9 级字阶 | 正文 15sp（≥ 6.1.3 的 14 号下限），全部用 sp |
| `Dimens.kt` | 间距 / 圆角 / 海拔 / 动效时长 / 尺寸 | 按压反馈 90ms（≤ 6.1.3 的 100ms）；最小可点 48dp |
| `Theme.kt` | `ZhiJingTheme` 入口 + `ZjShapes` | 默认 `dynamicColor = false` |

**为什么把「参数」单独拆文件**：对应说明书 7.2「界面代码与参数解耦」——间距、圆角、动效是最容易随手写死 `16.dp` / `300` 的东西，集中成对象后改密度只动一个文件。

---

## 4. 一处必须写进代码的决策：关闭动态取色

Compose 模板默认 `dynamicColor = true`（Android 12+ 跟随壁纸取色）。对本产品**必须关闭**，三条理由：

1. 6.1.1 要求「浅色为主」——跟随壁纸会给出深色紫、粉色系界面，直接违背；
2. 四态色（未探测/已验证/已掌握/易混淆）必须与主色保持稳定对比，动态取色会让「易混淆」在某些壁纸下与主色撞色，状态识别失效；
3. 答辩截图与《研究报告》里的界面图会因人而异，无法作为统一交付物。

处理：`ZhiJingTheme(dynamicColor = false)` 为默认；若未来要在设置页开「跟随壁纸取色（实验）」，作为显式开关传入，默认仍是关。

## 5. 与说明书 6.1 的逐条映射

| 说明书条款 | 落地位置 | 状态 |
|---|---|---|
| 6.1.1 整体风格（简洁、浅色、深浅色跟随、插画统一） | `Color.kt` 纸墨色板 + `mock` 庭院主题树 / 养成系动物插画 | ✅ |
| 6.1.2 主要页面（首页/问答/庭院/详情/对照/设置） | 6 页原型 `ui/mock/`，每页承载内容对齐 6.1.2 | ✅ |
| 6.1.3 交互（100ms 反馈、可取消思考、2.5s 轻提示、确认框、异常说明、14 号字、字号缩放） | `Dimens.kt` 动效时长 + `Type.kt` 字号 + 原型状态覆盖 | ✅ |
| 3.2 内置资源（庭院图标/连线/生长动画、动物四阶段部件） | 原型中的主题树 SVG + 动物「萌芽」阶段部件 | 部分（四阶段动画待美术） |
| 7.4 开发要求（Android 10+、Kotlin、Android Studio） | Compose + Material 3 实现基线 | ✅ |
