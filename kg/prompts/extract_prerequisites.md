# 前置关系抽取提示词（卡片级）

> 对应设计：**前置关系限定在卡片之间，必须前置画实线、推荐前置画虚线。**
> 依据来源：模型自身的领域理解（系统不提供课程资料，因此**属于推断，不是核实过的结论**）。

## 1. 与其它关系形式的区别

| 形式 | 含义 | 方向 | 谁生成 | 视觉 |
|---|---|---|---|---|
| 大纲层级 | 章节 → 卡片 | 树 | 本地 | 细实线 |
| **前置关系** | 学 A **之前**必须先学 B | **有向** | **模型** | 必须=实线，推荐=虚线 |
| 交叉链接 | A 与 B「有关」 | 无向 | 本地（词共现） | 细虚线 |

三者是不同语义，**不能混用**。尤其「相关」不等于「前置」：
两张卡都提到「张量形状」不代表要先学其中一张。

## 2. 判定标准

### 必须前置（required）

> **不先学 A，学 B 时会明显卡住或学不懂。**

满足以下任一即算：

- B 的解释里用到了 A 才定义的概念；
- B 的方法只能在 A 成立的前提下使用；
- 跳过 A 直接学 B，会产生体系性误解（不是「少知道一点」）。

### 推荐前置（recommended）

> 学 A 对理解 B **有帮助**，但不学也能跟上 B。

- A 提供背景、动机或工程直觉；
- A 是 B 的常见对照物（学了对比更清楚）；
- A 与 B 共享同一套记号或术语。

### 不算前置

- 只是「话题相关」；
- 只是「顺序相邻」（章节编号先后 ≠ 学习前置）；
- 只是「都提到了同一个词」。

## 3. 数量限制

| 规则 | 上限 |
|---|---|
| 每张卡最多被指出几条前置 | **3** 条 |
| 必须前置占比 | 一般不超过一半 |
| 整体密度 | 卡片数 N 时，边数约 **1.2N ~ 1.8N** |

超过就说明判得太松 —— 前置的价值的**稀疏**：全是前置等于没有前置。

## 4. system prompt（原样投喂）

```
你是课程前置关系的判定器，只输出 JSON，不解释、不使用 Markdown。

输入是一组学习卡片（id + 标题 + 摘要）。你的任务：判断卡片之间的**学习前置**
——学某张卡之前，需要先学哪张卡。

只输出有向关系，方向是「先学 → 后学」。

判定两档：
- required：不先学前者，学后者会明显卡住或学不懂
- recommended：有帮助，但不学也能跟上

不算前置的情况：
1. 只是话题相关、共享一个术语
2. 只是大纲顺序相邻（编号先后不等于学习前置）
3. 前者是后者的对照物但没有依赖关系时，最多算 recommended

数量约束：
- 每张卡最多被指出 3 条前置
- 边的总数控制在卡片数的 1.2 到 1.8 倍之间
- required 不要超过总数的一半

reason 用一句话说明依赖点（不超过 20 字），不要复述标题。

输出格式：
{"prerequisites":[
  {"from":"<先学卡的 id>","to":"<后学卡的 id>","kind":"required","reason":"..."}
]}

没有合理前置时输出 {"prerequisites":[]}。
```

## 5. user prompt 模板

```
卡片（id | 标题 | 摘要）：
{cards}
```

`{cards}` 每行一张，形如 `crd.s1-1-linear | 1.1 Linear 层 | 做仿射变换`。

## 6. 输出契约

```json
{
  "prerequisites": [
    {"from": "crd.s1-1-linear", "to": "crd.s1-2-relu", "kind": "required", "reason": "ReLU 作用在 Linear 的输出上"},
    {"from": "crd.s1-3-softmax", "to": "crd.s1-4", "kind": "recommended", "reason": "交叉熵常与 Softmax 配套理解"}
  ]
}
```

写入 `graph.json` 的顶层 `prerequisites` 字段。缺省时加载器按空处理，不影响老数据。

## 7. 质量约束（必须由代码校验，不靠模型自觉）

| 检查 | 处理 |
|---|---|
| `from` / `to` 不是已知卡片 id | 丢弃该条 |
| `from == to` | 丢弃 |
| 形成环（A→B→A） | 丢弃造成环的那条 |
| 单卡入边 > 3 | 按 required 优先截断 |
| 边密度超上限 | 按 required 优先截断 |

环检测与密度限制放在 `PrerequisiteValidator` 里，与解析器分离。

## 8. 诚实标注

系统不提供课程资料，因此这些前置关系是**模型推断**，不是核实过的课程事实。

UI 上必须让用户知道这一点 —— 结构图图例写明「前置由 AI 推断」。
这与 `cs-math-skill-tree`（每条前置都有 CS2023 原文依据）是本质区别。
